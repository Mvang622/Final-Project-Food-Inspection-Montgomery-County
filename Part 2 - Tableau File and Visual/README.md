# Part 2 - Tableau File and Visual 

This folder contains the interactive Tableau workbooks, high-resolution exported chart images, and presentation materials used to visualize food safety inspection patterns across Montgomery County[cite: 14].

## Folder Contents

### 1. `Tableau Files/`
Contains the packaged Tableau workbooks built for exploratory and visual analysis[cite: 14]:
* **`Project for class.twb` (Question 1):** Evaluates adverse inspection rates across all 18 establishment categories (`Outcomes by Category`) and compares initial routine visits against follow-up reinspections (`Category by Type Heat Map`)[cite: 3].
* **`Projecct for class Q2.twb` (Question 2):** Pivots all 16 individual health code compliance items to rank county-wide violation frequencies (`Top Violations Ranking`), map hazard hotspots by facility type (`Violations by Category Matrix`), and track seasonal refrigeration strain (`Violations by Season`)[cite: 2].

### 2. `Tableau Visuals/`
Contains the high-resolution `.png` chart exports formatted with clear labels, sorted risk rankings, and consistent color legends for direct inclusion in the Business Case Report and presentation slides[cite: 14].

### 3. `Presentation/` 
Contains the final PowerPoint presentation deck summarizing the exploratory visualizations, key operational findings, predictive modeling results, and strategic recommendations for health inspectors.

## Key Visual Insights
* **Facility Risk Hierarchy:** Public Middle Schools (40.5%), Restaurants (36.2%), and Carry Out locations (33.2%) experience the highest adverse outcome rates[cite: 5], while Snack Bars (11.2%) and Caterers (12.7%) experience the lowest[cite: 5].
* **The Reinspection Effect:** Follow-up reinspections reduce critical violation rates across every establishment category (falling to ~11% overall), confirming rapid corrective action following county citations[cite: 5].
* **Top Hazards & Seasonality:** Cold Holding Temperature (19.9% of visits) and Rodents/Insects (15.5% of visits) dominate county-wide citations[cite: 5], with cold holding failures climbing from 18.5% in winter to 21.8% in summer due to heat-induced refrigeration strain[cite: 6].
